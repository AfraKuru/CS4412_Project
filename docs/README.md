# Project Documents

This folder contains all formal written reports for each milestone of the CS 4412 Data Mining project.

Each document reflects a different stage of the Knowledge Discovery in Databases (KDD) process, from initial proposal to full implementation and analysis.

---

## Contents

### M1_The_Proposal.pdf
- Initial project proposal
- Defines dataset, discovery questions, and planned methods
- Establishes the overall direction of the project

---

### M2_Summary_Report.pdf
- Exploratory Data Analysis (EDA)
- Data preprocessing decisions
- Initial clustering using K-Means
- Early insights into musical structure

---

### M3_Implementation_and_Analysis.pdf
- Full data mining pipeline implementation
- Dimensionality reduction using PCA
- Clustering using K-Means and DBSCAN
- Anomaly detection using Local Outlier Factor (LOF)
- Evaluation and interpretation of results

---

## Notes

- All reports are written in IEEE format.
- Each milestone builds on the previous one, following the full data mining workflow.
- The final results and conclusions are presented in the M4 report (located separately).
