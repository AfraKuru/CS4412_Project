# Discovering Latent Musical Structure Using Spotify Audio Features

**Course:** CS 4412 Data Mining  
**Student:** Afra Kurudirek  

## Project Overview
This project applies data mining techniques to discover latent musical structures using Spotify audio feature data. The focus is on pattern discovery and interpretation rather than prediction.

## Dataset
Spotify Tracks Dataset (Kaggle)  
Over 110,000 tracks with audio features including danceability, energy, tempo, valence, and popularity.
Dataset source:(https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset)
               (https://www.kaggle.com/datasets/tomigelo/spotify-audio-features) 


## Planned Techniques
- Data preprocessing and normalization
- Dimensionality reduction using PCA
- Clustering (K-Means, DBSCAN)
- Anomaly detection
- Interpretation of discovered patterns
