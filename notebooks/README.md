# Notebooks

This folder contains all Jupyter notebooks used throughout the project. Each notebook corresponds to a specific project milestone and documents the progression of the data mining pipeline.

---

## Contents

### M2_Initial_Implementation.ipynb
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature selection and scaling
- Initial clustering using K-Means
- First insights into musical structure

---

### M3_Complete_Implementation_and_Analysis.ipynb
- Full data mining pipeline
- Dimensionality reduction using PCA
- Clustering using K-Means and DBSCAN
- Anomaly detection using Local Outlier Factor (LOF)
- Evaluation metrics (Silhouette Score, Davies-Bouldin Index)
- Final results and interpretation
